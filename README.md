# Κάθοδος · project page

Project page and playable build of **Κάθοδος**, a Greek daily rarity game: seven prompts a day, fifty seconds each,
and the rarer your valid answer, the deeper you sink. Next version: **Σφουγγαρομύριο**, the sponge divers of Kalymnos.

- Project page: https://ennui92.github.io/kathodos-site/
- Play: https://ennui92.github.io/kathodos-site/play/

`play/index.html` is a copy of `dist/kathodos.html` from the game repo (`node tools/build.js`). Outside Claude the game
keeps your progress in the browser only; the shared "what others said" numbers need the Claude-hosted version.
